# 6. Generative AI and Vibe Coding

## 6.1. What Is Generative AI?

#   

Generative AI is artificial intelligence that creates new text, images, music, video, or code in response to a user’s request.

A student may ask AI to:

- Create English vocabulary questions.
    
- Build a quiz app.
    
- Make the buttons larger.
    
- Change the interface to Mongolian.
    
- Find and correct an error.
    

## 6.2. What Is Vibe Coding?

#   

Vibe coding is a way of developing an app by describing the intended program in ordinary language and using code generated or modified by AI.

Traditional coding:

1. Learn programming syntax.
    
2. Write code manually.
    
3. Find errors manually.
    
4. Implement each function separately.
    

Vibe coding:

1. Describe the app you want to build.
    
2. AI generates the code.
    
3. Run the result.
    
4. Describe what should be changed.
    
5. Continue revising the app with AI.
    

## 6.3. Does AI Always Produce a Correct Result?

#   

No.

An AI-generated app may have the following problems:

- A button does not work.
    
- An answer is incorrect.
    
- Text is cut off on the screen.
    
- A Mongolian translation is unnatural.
    
- A required function is missing.
    
- An unrequested function has been added.
    
- An error occurs when the app is run.
    

Students must therefore run and verify every AI-generated result.
