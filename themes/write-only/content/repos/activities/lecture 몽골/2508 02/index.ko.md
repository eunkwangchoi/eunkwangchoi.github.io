# 3. Google 계정 만들기

## 3.1. 가입 전 확인

#   

Google 계정을 이미 가지고 있다면 새로 만들 필요가 없다.

다음 중 하나가 있으면 기존 Google 계정을 사용할 수 있다.

- `@gmail.com`으로 끝나는 이메일 주소
    
- YouTube에 로그인할 때 사용하는 Google 계정
    
- Google Drive 또는 Google Classroom에서 사용하는 계정
    
- Android 스마트폰에 등록된 개인 Google 계정
    

학교나 기관에서 제공한 계정은 외부 서비스 접속이 제한될 수 있다. 가능하면 학생 개인 계정을 사용한다.

## 3.2. 연령에 관한 주의사항

#   

- 대한민국에서는 만 14세 이상이 일반 Google 계정을 직접 관리할 수 있다.
    
- 만 14세 미만 학생은 보호자가 Family Link 등을 통해 계정을 만들고 관리해야 할 수 있다.
    
- Google 계정이 있어도 Google AI Studio는 18세 미만이면 사용할 수 없다.
    
- 실제 생년월일을 정확하게 입력해야 한다.
    
- 가입을 위해 나이를 허위로 입력하지 않는다.
    

## 3.3. 준비물

#   

- 본인이 사용할 이메일 주소 또는 새 Gmail 주소
    
- 기억할 수 있는 비밀번호
    
- 본인 또는 보호자가 확인할 수 있는 휴대전화
    
- 복구용 이메일 주소가 있다면 해당 주소
    
- 보호자 동의가 필요한 경우 보호자의 확인
    

## 3.4. 컴퓨터에서 Google 계정 만들기

#   

1. Chrome 또는 다른 웹 브라우저를 실행한다.
    
2. 다음 주소로 이동한다.
    
    [https://accounts.google.com](https://accounts.google.com/)
    
3. 화면 아래의 `계정 만들기` 또는 `Create account`를 누른다.
    
4. `개인용` 또는 `For my personal use`를 선택한다.
    
5. 이름과 성을 입력한다.
    
6. `다음`을 누른다.
    
7. 실제 생년월일과 성별 정보를 입력한다.
    
8. 사용할 Gmail 주소를 선택한다.
    
9. 제시된 주소가 마음에 들지 않으면 `내 Gmail 주소 만들기`를 선택한다.
    
10. 다른 학생과 중복되지 않는 주소를 입력한다.
    

예시:

- `student.name2026@gmail.com`
    
- `mongolcoding26@gmail.com`
    
- `myapp.student@gmail.com`
    

11. 비밀번호를 만든다.
    
12. 같은 비밀번호를 한 번 더 입력한다.
    
13. `다음`을 누른다.
    
14. Google이 휴대전화 확인을 요구하면 화면의 안내에 따른다.
    
15. 휴대전화로 받은 인증번호를 입력한다.
    
16. 복구 이메일을 입력할 수 있다면 입력한다.
    
17. 전화번호와 복구 이메일을 확인한다.
    
18. 개인정보 보호 및 이용약관을 읽는다.
    
19. `동의` 또는 `I agree`를 선택한다.
    
20. Google 계정 화면이 나타나면 가입이 완료된 것이다.
    

## 3.5. 휴대전화 인증이 나타나는 경우

#   

Google은 보안 또는 중복 가입 방지를 위해 다음 절차를 요구할 수 있다.

1. 화면에 QR 코드가 나타난다.
    
2. 스마트폰 카메라로 QR 코드를 촬영한다.
    
3. 스마트폰 화면에 나타나는 주소를 연다.
    
4. 본인 확인 절차를 진행한다.
    
5. 문자 인증번호가 전송되면 해당 번호를 입력한다.
    

휴대전화 인증 절차는 계정이나 접속 환경에 따라 다르게 나타날 수 있다.

인증이 되지 않는 경우 다음을 확인한다.

- 국가번호가 대한민국 `+82`로 되어 있는가?
    
- 전화번호 앞의 `0`을 제외해야 하는 화면인가?
    
- 인증번호를 여러 번 잘못 입력하지 않았는가?
    
- 같은 전화번호로 너무 많은 계정을 만들지 않았는가?
    
- 학교 공용 인터넷에서 가입 요청이 과도하게 발생하지 않았는가?
    

계속 실패하면 반복해서 가입을 시도하지 말고 강사에게 알린다.

# 4. Google AI Studio 접속 확인

## 4.1. Google AI Studio란?

#   

Google AI Studio는 Google의 생성형 AI 모델을 시험하고, 프롬프트를 작성하며, 코드를 생성할 수 있는 웹 기반 도구이다.

이번 수업에서는 강사가 다음 과정을 시연한다.

1. 만들고 싶은 앱을 문장으로 설명한다.
    
2. AI가 앱의 구조와 코드를 제안한다.
    
3. 결과를 수정하도록 다시 요청한다.
    
4. 생성된 코드를 Replit에서 실행한다.
    

## 4.2. 학생 이용 기준

#   

### 18세 이상 학생

1. Google 계정으로 로그인한다.
    
2. [https://aistudio.google.com](https://aistudio.google.com/) 에 접속한다.
    
3. 서비스 약관 또는 이용 안내가 나타나면 내용을 확인한다.
    
4. 요구되는 동의 절차를 진행한다.
    
5. 프롬프트 입력 화면이 나타나는지 확인한다.
    

### 18세 미만 학생

- 직접 접속하거나 로그인하지 않는다.
    
- 강사가 공유하는 화면을 관찰한다.
    
- 강사의 프롬프트를 학습지에 기록한다.
    
- 실제 앱 제작은 Replit에서 진행한다.
    
- 다른 사람의 18세 이상 계정을 빌려 사용하지 않는다.
    
- 생년월일을 허위로 수정하지 않는다.
    

## 4.3. 접속할 수 없는 경우

#   

다음과 같은 이유로 Google AI Studio에 접속하지 못할 수 있다.

- 사용자가 18세 미만인 경우
    
- Google 계정의 생년월일이 확인되지 않은 경우
    
- 학교 또는 기관이 관리하는 계정인 경우
    
- 보호자 관리 계정인 경우
    
- 서비스가 지원되지 않는 국가나 네트워크로 인식되는 경우
    
- VPN 또는 프록시를 사용하는 경우
    
- 기관 네트워크에서 접속이 제한된 경우
    

학생 개인이 우회 방법을 시도하지 않는다. 수업에서는 강사의 시연으로 대체한다.

# 5. Replit 계정 만들기

## 5.1. Replit이란?

#   

Replit은 웹 브라우저에서 앱과 웹사이트를 만들고 실행할 수 있는 개발 플랫폼이다.

이번 강의에서 학생은 Replit을 이용해 다음 작업을 한다.

- 앱 프로젝트 생성
    
- AI에게 앱 제작 요청
    
- 코드 확인
    
- 앱 실행
    
- 디자인 수정
    
- 오류 수정
    
- 결과물 저장 및 공유
    

## 5.2. Replit 이용 전 연령 및 보호자 확인

#   

Replit은 미성년자가 이용할 경우 보호자의 동의와 관리가 필요할 수 있다.

- 18세 미만 학생은 보호자에게 수업에서 Replit을 이용한다는 사실을 알린다.
    
- 13세 미만 학생은 보호자의 사전 서면 동의가 필요하다.
    
- 실제 생년월일을 정확하게 입력한다.
    
- 다른 학생의 계정을 함께 사용하지 않는다.
    
- 유료 요금제를 신청하거나 결제 정보를 입력하지 않는다.
    
- 무료 Starter 요금제를 사용한다.
    

## 5.3. 가장 간단한 가입 방법: Google 계정으로 계속하기

#   

1. 브라우저에서 다음 주소로 이동한다.
    
    [https://replit.com/signup](https://replit.com/signup)
    
2. `Sign up` 또는 `Create a Replit account` 화면을 확인한다.
    
3. `Continue with Google`을 선택한다.
    
4. 앞에서 준비한 개인 Google 계정을 선택한다.
    
5. Google 로그인 화면이 나타나면 비밀번호를 입력한다.
    
6. Replit에 전달되는 정보의 범위를 확인한다.
    
7. `계속` 또는 `Continue`를 선택한다.
    
8. Replit 이용약관 및 개인정보 관련 동의 화면을 확인한다.
    
9. 필요한 항목에 동의한다.
    
10. 사용자 이름을 정하는 화면이 나타나면 영어 문자와 숫자를 사용해 입력한다.
    
11. 학습 목적 또는 이용 목적을 묻는 화면이 나타나면 학생에게 가장 가까운 항목을 선택한다.
    
12. 유료 요금제 안내가 나타나면 결제하지 않고 무료 요금제를 선택하거나 화면을 닫는다.
    
13. Replit 홈 화면이 나타나면 가입이 완료된 것이다.
    

## 5.4. 이메일 주소로 가입하는 방법

#   

Google 계정 연동이 되지 않는 경우에만 사용한다.

1. [https://replit.com/signup](https://replit.com/signup) 에 접속한다.
    
2. 이메일 주소로 가입하는 항목을 찾는다.

4. Replit에서 보낸 인증 이메일을 확인한다.
    
5. 이메일 안의 인증 버튼 또는 링크를 누른다.
    
6. Replit 화면으로 돌아온다.
    
7. 사용자 이름과 비밀번호를 설정한다.
    
8. 이용약관 및 개인정보 관련 내용을 확인한다.
    
9. 가입을 완료한다.
    

이메일 인증 메시지가 보이지 않으면 다음 폴더를 확인한다.

- 받은편지함
    
- 스팸함
    
- 프로모션함
    
- 정크 메일함

# 6. 생성형 AI와 Vibe Coding

## 6.1. 생성형 AI란?

#   

생성형 AI는 사용자의 요청을 바탕으로 새로운 텍스트, 이미지, 음악, 영상 또는 코드를 만들어 주는 인공지능이다.

학생은 AI에게 다음과 같이 요청할 수 있다.

- 영어 단어 문제를 만들어 줘.
    
- 퀴즈 앱을 만들어 줘.
    
- 버튼을 크게 만들어 줘.
    
- 화면을 몽골어로 바꿔 줘.
    
- 오류를 찾아서 고쳐 줘.
    

## 6.2. Vibe Coding이란?

#   

Vibe Coding은 만들고 싶은 프로그램을 자연어로 설명하고, AI가 생성하거나 수정한 코드를 이용해 앱을 개발하는 방식이다.

전통적인 코딩:

1. 프로그래밍 문법을 배운다.
    
2. 코드를 직접 작성한다.
    
3. 오류를 직접 찾는다.
    
4. 기능을 하나씩 구현한다.
    

Vibe Coding:

1. 만들고 싶은 앱을 설명한다.
    
2. AI가 코드를 만든다.
    
3. 결과를 실행한다.
    
4. 원하는 부분을 다시 설명한다.
    
5. AI와 함께 반복해서 수정한다.
    

## 6.3. AI가 모든 것을 정확하게 만드는가?

#   

그렇지 않다.

AI가 만든 앱에는 다음과 같은 문제가 생길 수 있다.

- 버튼이 작동하지 않는다.
    
- 정답이 잘못되어 있다.
    
- 화면의 글자가 잘린다.
    
- 몽골어 번역이 부자연스럽다.
    
- 일부 기능이 빠져 있다.
    
- 요청하지 않은 기능이 추가된다.
    
- 실행 과정에서 오류가 발생한다.
    

따라서 학생은 AI가 만든 결과를 반드시 실행하고 확인해야 한다.
