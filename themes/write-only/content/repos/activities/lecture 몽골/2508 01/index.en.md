# Session 1 (August 5) — Introduction to Vibe Coding and Guided App Building

#   

- Objective: Understand the basic concepts of generative AI and vibe coding, and build a simple web application by following the instructor’s demonstration.
    
- Tools: Google AI Studio, Replit
    
- Output: English vocabulary quiz web application
    
- Language support: English as the primary instructional language, Korean as a supplementary language, and Mongolian output supported through AI
    

#   

1. Introduction to the basic concepts of generative AI and vibe coding
    
2. Overview of the respective roles and basic functions of Google AI Studio and Replit
    
3. Instructor demonstration of the complete process for building an English vocabulary quiz application
    
4. Students follow the demonstrated process and build the same web application
    
5. Modification of basic elements, including the application title, quiz content, and colors
    
6. Running the completed application and checking the results
    
7. Questions and answers, followed by an introduction to the next session
    

#   

# Session 2 (August 7) — Adding Features and Modifying an App

#   

- Objective: Learn how to add new features to an existing application and how to communicate specific revision requests to AI.
    
- Tools: Google AI Studio, Replit
    
- Output: An individually customized quiz or game application with additional features
    
- Language support: Standard English prompt templates, supplementary explanations in Korean, and the option to display the application interface in Mongolian
    

#   

1. Run the application created in the previous session and review the main development process
    
2. Instructor demonstration of adding scoring, hints, a timer, and a restart function
    
3. Practice basic prompts such as `Add a score system` and `Add a timer`
    
4. Students select and add individual features:
    
    - Score display
        
    - Hint function
        
    - Additional questions
        
    - Timer
        
    - Restart button
        
    - Background and text color changes
        
    - Mongolian-language interface
        
5. Transform the existing English vocabulary quiz into an application with a different subject:
    
    - Mathematics quiz
        
    - Science quiz
        
    - History quiz
        
    - Number guessing game
        
    - Personality-type test
        
6. Share revised applications and resolve errors
    
7. Questions and answers
    

#   

# Session 3 (August 12) — Planning and Building Your Own App

#   

- Objective: Select or adapt one of the suggested ideas, then plan and build an original application.
    
- Tools: Google AI Studio, Replit
    
- Output: An initial web application developed individually or in a team
    
- Assignment: Improve the application’s functions and prepare the presentation content for the next session
    

#   

1. Introduction to the basic elements of application planning:
    
    - Intended users
        
    - Problem to be addressed
        
    - Required functions
        
    - Information to be displayed on the screen
        
2. Instructor demonstration of the planning and development process for a career recommendation application
    
3. Review the suggested project ideas and select a topic
    
    **Learning**
    
    - English vocabulary memorization app
        
    - Mongolian–English flashcard app
        
    - Mathematics practice app
        
    - Science or history quiz
        
    - Test-preparation quiz app
        
    
    **School Life**
    
    - Homework management app
        
    - Class schedule app
        
    - Study planner
        
    - School or club introduction app
        
    - School-supplies checklist
        
    
    **Games**
    
    - Rock-paper-scissors game
        
    - Number guessing game
        
    - Memory game
        
    - Reaction-speed game
        
    - Random quiz game
        
    
    **Career and Daily Life**
    
    - Career recommendation app
        
    - Interest discovery app
        
    - Mongolia travel guide
        
    - Food recommendation app
        
    - Exercise tracker
        
    - Daily goal-setting app
        
    
    **Information Services**
    
    - Mongolian culture introduction app
        
    - Guide to living in Korea
        
    - Korean expression learning app
        
    - English conversation practice app
        
    - School-life help app
        
4. Write a brief project plan individually or in teams
    
5. Generate application code with AI and run it in Replit
    
6. Revise the title, wording, functions, and design
    
7. Instructor circulates to provide guidance and resolve errors
    
8. Explanation of the presentation assignment

# Session 4 (August 14) — App Completion and Project Presentation

#   

- Objective: Complete the application by improving its functions and design, and present its development process and intended use.
    
- Tools: Google AI Studio, Replit
    
- Output: A completed individual or team web application and project presentation
    
- Presentation language: Students may choose Korean or English and may use Mongolian explanations within the application interface when necessary
    

#   

1. Check the progress of the project developed during the previous session
    
2. Instructor demonstration of methods for improving application quality:
    
    - Error correction
        
    - Improved placement of buttons and text
        
    - Addition of usage instructions
        
    - Prevention of invalid input
        
    - Design adjustments for mobile screens
        
3. Practice revision prompts such as `Fix the errors`, `Make it easier to use`, and `Improve the design`
    
4. Final improvement of application functions and design, individually or in teams
    
5. Prepare the presentation materials and demonstration sequence
    
6. Project presentations:
    
    - Application name
        
    - Purpose of the application
        
    - Intended users
        
    - Core functions
        
    - Requests made to AI
        
    - Elements revised during development
        
7. Students test one another’s applications and provide feedback
    
8. Course review and questions and answers

# Instructional Principles

#   

1. The instructor first demonstrates the complete development process, after which students follow the same sequence.
    
2. Screen-based demonstrations and repeated practice are emphasized over verbal explanation.
    
3. English prompts are provided as fill-in-the-blank templates rather than requiring students to compose complete sentences independently.
    
4. Students who have difficulty with Korean or English may copy the provided prompts and modify only the essential words.
    
5. Mongolian, which all students share as a common language, is used for the application interface and AI-generated explanations.
    
6. The instructor gives directions in Korean and English, while AI is used as a supplementary tool for Mongolian translation and explanation.
    
7. Students who find it difficult to add functions independently select one from a prepared list of features.
    
8. Every student is expected to complete at least one functioning application, while the number and complexity of features are adjusted according to proficiency.
