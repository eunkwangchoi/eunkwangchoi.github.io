# 수업 운영 원칙

#   

1. 강사가 전체 제작 과정을 먼저 시연한 후 학생들이 동일한 순서로 따라 한다.
    
2. 설명보다 화면 시연과 반복 실습의 비중을 높인다.
    
3. 영어 프롬프트는 문장 전체를 직접 작성하게 하기보다 빈칸형 템플릿으로 제공한다.
    
4. 한국어 또는 영어가 어려운 학생은 프롬프트를 복사한 뒤 핵심 단어만 수정한다.
    
5. 학생들이 공통으로 사용하는 몽골어는 앱의 화면 언어와 AI 설명 언어로 활용한다.
    
6. 강사는 한국어와 영어로 지시하고, AI를 몽골어 번역 및 설명의 보조 수단으로 활용한다.
    
7. 학생이 직접 기능을 추가하기 어려운 경우에는 사전에 제시된 기능 목록에서 하나를 선택하도록 한다.
    
8. 모든 학생이 최소 한 개의 작동하는 앱을 완성하도록 하되, 숙련도에 따라 기능의 수와 난이도를 조정한다.
