# 4. Багшийн үзүүлэн I — Хиймэл оюунаар тоглоом бүтээлгэх

## 4.1. Өнөөдөр бүтээх тоглоом

**Number Guessing Game — Тоо таах тоглоом**

Компьютер 1-ээс 100 хүртэлх нэг тоог санамсаргүй сонгоно.

Тоглогч тэр тоог таах ёстой.

Тоглоомын дүрэм:

- Оруулсан тоо зөв хариултаас бага бол `Too low!`
    
- Оруулсан тоо зөв хариултаас их бол `Too high!`
    
- Зөв таавал `Correct!`
    
- Зөв хариултыг олох хүртэл тоглоом үргэлжилнэ
    

## 4.2. Эхний промпт

#   

Google AI Studio дээр дараах промптыг ашиглана.

```
Create a very simple number guessing game in Python for beginner students.

Rules:
- Choose a random number from 1 to 100.
- Ask the player to enter a number.
- If the guess is too low, print "Too low!"
- If the guess is too high, print "Too high!"
- If the answer is correct, print "Correct!"
- Keep asking until the player gets the correct answer.

Requirements:
- Keep the Python code simple.
- Add short comments.
- Do not use classes.
- Explain the important parts after the code.
```

## 4.3. Эхлээд хиймэл оюуны бүтээсэн кодыг унших

#   

Үндсэн бүтэц нь ихэвчлэн дараахтай төстэй байна.

```
import random

answer = random.randint(1, 100)

while True:
    guess = int(input("Guess a number from 1 to 100: "))

    if guess < answer:
        print("Too low!")
    elif guess > answer:
        print("Too high!")
    else:
        print("Correct!")
        break
```

Кодыг шууд цээжлэх шаардлагагүй.

Эхлээд аль мөр ямар ажил хийж байгааг олно.
