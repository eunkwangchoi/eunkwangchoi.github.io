# 1. 강의 개요

<h3>강의명</h3>

Edit Mode  
— 메시 다루기

<h3>강의 목표</h3>

- Edit Mode에서 Vertex, Edge, Face를 선택할 수 있다.
- Box, Loop, Linked 등 Select 방식을 활용할 수 있다.
- Proportional Editing, Knife, Merge, Delete 등 기본 메시 정리 기능을 활용할 수 있다.
- 메시의 열린 구조, 겹친 점, 불필요한 면을 확인하고 정리할 수 있다.
- 3D 프린팅을 위한 “깨끗한 메시”의 중요성을 이해할 수 있다.

<h3>실습의 흐름</h3>

1. 선택하기 — Vertex, Edge, Face 선택 방식 확장
2. 빠르게 고르기 — Box Select, Loop Select, Linked Select
3. 자르기 — Knife Tool로 원하는 위치에 선 추가
4. 정리하기 — Delete, Dissolve, Merge 구분
5. 확인하기 — Wireframe, X-Ray, Face Orientation으로 구조 점검
6. 고치기 — 겹친 점 병합, 열린 면 확인, 불필요한 요소 제거

<br>

# 2. 팁

## 2.1 Wireframe/Overlay

1. `Z` → **Wireframe**  
	또는 Viewport 상단 Shading 아이콘에서 Wireframe 선택
2. Overlay → Wireframe 체크

## 2.2 작업 중 취소

1. `Esc` 또는 우클릭

## 2.3 Shade Smooth/Flat

1. 오브젝트 선택 및 우클릭
2. **Shade Smooth** 또는 **Shade Flat**

- Smooth → 부드러운 표면
- Flat → 면이 분명하게 보임

## 2.4 Face Orientation

1. Viewport 상단 Overlay 클릭
2. Face Orientation 체크
3. `Alt` + `N` → Flip으로 뒤집어 보기

- 빨강 → 안쪽 방향

## 2.5 N Panel in Sidebar

1. `N` 키
2. Item 탭 확인

- Location, Rotation, Scale 수치 확인

## 2.6 Undo History

1. 상단 메뉴에서  
	Edit → Undo History

<br>

# 3. 실습

## 실습 1. 선택 방식 확장

1. Cube 선택
2. `Tab` → Edit Mode
3. `1`, `2`, `3`으로 Vertex, Edge, Face 선택 전환
4. `A`로 전체 선택
5. `Alt` + `A` 또는 빈 공간 클릭으로 선택 해제
6. `B`로 Box Select
7. `C`로 Circle Select

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Vertex / Edge / Face 선택이 바뀌지 않는다

원인

- Object Mode 상태임
- Edit Mode에 들어가지 않음

해결

- `Tab` → Edit Mode 진입
- 이후 `1`, `2`, `3`으로 선택 모드 전환

### 오류 2. Box Select가 작동하지 않는다

원인

- 단축키를 잘못 입력함
- 선택 도구가 다른 상태로 유지됨

해결

- `B` 입력 후 마우스로 드래그
- 선택 해제 후 다시 시도

### 오류 3. Circle Select에서 빠져나오지 못한다

원인

- Circle Select는 별도 선택 모드처럼 작동함

해결

- `Esc` 또는 우클릭으로 종료

{{< /details >}}

## 실습 2. Loop Select로 구조 한 줄 선택

1. Cube 선택
2. `Tab` → Edit Mode
3. Edge 선택 모드
4. `Alt` + 클릭으로 Edge Loop 선택
5. 선택된 루프를 `G`로 이동해 변화 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. `Alt` + 클릭을 해도 루프가 선택되지 않는다

원인

- Edge 선택 모드가 아님
- 클릭 위치가 Edge 위가 아님
- 메시 구조가 루프를 형성하지 않음

해결

- `2` → Edge 선택 모드로 전환
- Edge 위를 정확히 클릭
- Cube처럼 규칙적인 메시에서 다시 시도

### 오류 2. 한 줄 전체가 아니라 일부만 선택된다

원인

- 메시가 끊겨 있음
- N-gon 또는 비정형 구조로 루프가 이어지지 않음

해결

- 단순 Cube에서 먼저 연습
- 메시 구조가 연결되어 있는지 확인

{{< /details >}}

## 실습 3. Linked Select로 연결된 부분 선택

1. 분리된 오브젝트 또는 복합 메시 준비
2. Edit Mode 진입
3. 한 부분의 Face 선택
4. `L`로 연결된 구조 선택
5. 선택된 부분만 이동 또는 분리 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. `L`을 눌렀는데 전체가 선택된다

원인

- 오브젝트 내부가 하나의 연결된 메시임

해결

- 분리된 구조가 포함된 예제 파일 사용
- 연결된 부분과 분리된 부분의 차이를 확인

### 오류 2. 원하는 부분이 선택되지 않는다

원인

- 마우스 위치가 선택하려는 구조 위에 있지 않음
- 이미 다른 요소가 선택되어 있음

해결

- 선택을 해제한 뒤 다시 시도
- 마우스를 원하는 구조 위에 올린 상태에서 `L` 입력

{{< /details >}}

## 실습 4. Knife Tool로 직접 선 추가

1. Cube 선택
2. Edit Mode
3. `K` → Knife Tool 실행
4. 원하는 면 위에 선을 그음
5. `Enter`로 확정

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Knife로 선을 그었는데 적용되지 않는다

원인

- `Enter`로 확정하지 않음

해결

- Knife 작업 후 반드시 `Enter` 입력

### 오류 2. 원하지 않는 위치에 선이 생긴다

원인

- 시점이 비스듬함
- 클릭 위치가 부정확함

해결

- 정면 / 측면 / 상단 뷰로 전환 후 작업
- 확대해서 점 위치 확인

### 오류 3. Knife Tool에서 빠져나오지 못한다

원인

- Knife 작업이 활성 상태로 남아 있음

해결

- `Esc` 또는 우클릭으로 취소
- `Enter`로 확정 후 종료

{{< /details >}}

## 실습 5. Delete vs. Dissolve

1. Edge 선택
2. `Del` 또는 `X` → Delete Edge
3. 되돌리기
4. `Del` 또는 `X` → Dissolve Edges

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Delete 후 면이 사라져 구멍이 생긴다

원인

- Delete는 선택 요소를 실제로 제거함

해결

- 형태를 유지하려면 Dissolve 사용
- `Ctrl` + `Z`로 되돌린 뒤 다시 시도

### 오류 2. Dissolve를 했는데 변화가 없어 보인다

원인

- 선택한 요소가 구조상 정리될 수 없는 위치임
- 시각적으로 변화가 작음

해결

- Edge를 선택한 뒤 Dissolve Edges 사용
- Wireframe으로 구조 변화 확인

### 오류 3. 의도하지 않은 면까지 사라진다

원인

- 선택 범위가 넓음
- Face를 삭제함

해결

- 선택 영역 확인 후 실행
- Vertex / Edge / Face 선택 모드 재확인

{{< /details >}}

## 실습 6. Merge by Distance로 겹친 점 정리

1. Edit Mode
2. 일부 Vertex를 같은 위치에 겹치게 이동
3. 전체 선택 `A`
4. `M` → By Distance
5. 병합 결과 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 병합이 되지 않는다

원인

- 점들이 충분히 가깝지 않음
- 선택된 Vertex가 없음

해결

- 병합할 Vertex 선택
- Merge Distance 값을 조금 늘림

### 오류 2. 너무 많은 점이 합쳐져 형태가 망가진다

원인

- Merge Distance 값이 너무 큼

해결

- 값을 작게 조정
- `Ctrl` + `Z`로 되돌린 뒤 다시 실행

### 오류 3. 겹친 점이 보이지 않는다

원인

- 겹친 Vertex는 화면상 구분이 어려움

해결

- 전체 선택 후 Merge by Distance 실행
- 하단 결과 메시지에서 병합된 점 개수 확인

{{< /details >}}

## 실습 7. Wireframe, X-Ray, Face Orientation 확인

1. 오브젝트 선택
2. `Z` → Wireframe
3. `Alt` + `Z` → X-Ray
4. Overlay → Face Orientation 체크
5. 빨강 방향 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Wireframe으로 바꿨는데 원래 화면으로 못 돌아간다

원인

- Shading 모드가 Wireframe으로 유지됨

해결

- `Z` → Solid 선택
- 또는 Viewport 오른쪽 상단 Solid 아이콘 클릭

### 오류 2. X-Ray를 켰는데 선택이 헷갈린다

원인

- 뒤쪽 요소까지 함께 보이고 선택될 수 있음

해결

- 필요한 경우 `Alt` + `Z`로 X-Ray 해제
- 정면/측면 뷰에서 선택

### 오류 3. Face Orientation을 켰더니 모델이 빨갛게 보인다

원인

- 면의 방향이 안쪽을 향함
- 법선 방향이 뒤집혔을 수 있음

해결

- Edit Mode에서 전체 선택 `A`
- `Alt` + `N` → Recalculate Outside

{{< /details >}}

# 4. 정리

1. 메시 작업의 시작은 기능이 아니라 선택이다
2. Vertex, Edge, Face 선택에 따라 같은 조작도 결과가 달라진다
3. Loop Cut은 구조를 계획적으로 나누는 도구이며, Knife는 원하는 위치를 직접 자르는 도구이다
4. Delete와 Dissolve는 결과가 다르며, 형태를 유지하려면 Dissolve를 사용한다
5. 겹친 점과 열린 구조는 오류의 원인이 되므로 Merge by Distance로 정리한다
6. Wireframe, X-Ray, Face Orientation을 통해 보이지 않는 구조를 확인한다

# 5. 과제(선택)

<h3>과제 1. 선택 방식 연습</h3>

- Vertex, Edge, Face 선택을 각각 수행
- Box Select, Loop Select, Linked Select 사용
- 선택 방식에 따른 결과 차이 확인

<h3>과제 2. 구조 분할 및 정리</h3>

- Cube 생성
- Loop Cut으로 2~3회 분할
- 일부 Edge를 Dissolve하여 구조 정리
- Delete와 결과 비교

<h3>과제 3. 메시 오류 정리</h3>

- 일부 Vertex를 겹치게 이동
- Merge by Distance 실행
- 병합 결과 확인

<h3>과제 4. 구조 확인 훈련</h3>

- Wireframe, X-Ray, Face Orientation 켜기
- 내부 구조 확인
- 뒤집힌 면이 있는 경우 수정

<h3>과제 5. 결과물 구상 보완</h3>

최종 프로젝트를 다음 기준으로 보완한다

1. 구조를 어떻게 나눌 것인가
2. 어떤 부분을 Edit로 만들 것인가
3. 어떤 부분을 Modifier로 처리할 것인가
