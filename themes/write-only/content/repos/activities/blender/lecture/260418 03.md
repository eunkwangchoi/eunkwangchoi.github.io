# 1. 강의 개요

<h3>강의명</h3>

개념의 전환  
— 구조로 이해하는 모델링

<h3>강의 목표</h3>

- Modifier를 활용한 형상 변형 과정을 복습하고 구조적으로 이해할 수 있다.
- Extrude, Inset, Bevel, Boolean의 역할을 구분할 수 있다.
- 형상 변형^Modifier^과 구조 생성^Edit^의 차이를 이해할 수 있다.
- 모델링을 “형태 제작”이 아닌 “구조 설계”로 인식할 수 있다.
- 이후 프로젝트 제작을 위한 기본 모델링 원칙을 정립할 수 있다.

<h3>실습의 흐름</h3>

1. 복습하기 — Modifier 실습 결과 확인 및 재적용
2. 나누기 — Inset으로 구조 분할
3. 늘리기 — Extrude로 구조 확장
4. 다듬기 — Bevel로 모서리 처리
5. 제거하기 — Boolean으로 구조 절삭
6. 정리하기 — Edit와 Modifier의 역할 비교 및 구조 확인

# 2. 팁

## 2.1 Spacebar 설정 

1. 상단 메뉴에서  
    **Edit** → **Preferences**  
2. 왼쪽 메뉴에서 **Keymap** 
3. **Spacebar Action** 항목 확인

## 2.2 Frame Selected

오브젝트가 보이지 않거나 화면에서 벗어날 때    
가장 빠른 해결 방법  

1. Outliner에서 오브젝트 선택
2. 키패드에서 `/` (구버전은 `.`)

## 2.3 Transform Orientation

1. Viewport 상단  
	 **Global** / **Local** 드롭다운 메뉴

- Global
    - 세계 기준 축
    - 항상 수평/수직 유지
    - 정렬 및 위치 이동 시 사용
- Local
    - 오브젝트 기준 축
    - 오브젝트와 축이 함께 회전
    - 기울어진 오브젝트 수정 시 사용

## 2.4 Modifier ON/OFF

1. 오브젝트 선택
2. Properties → Modifier 탭
3. Modifier 아이콘 중 Realtime 클릭

- ON → Modifier 적용 상태
- OFF → 원본 상태

## 2.5 Apply Scale

1. 오브젝트 선택
2. `Ctrl` + `A`
3. Scale

- Scale 값이 (1, 1, 1)로 초기화
- 현재 크기를 기준값으로 설정

## 2.6 Object to Grid

### 2.6.1 Snap to Ground

1. 오브젝트 선택
2. `Shift` + `S`
3. **Selection to Grid**   
	1. 또는 **Selection to Cursor** (커서를 0,0,0에 둔 경우)

### 2.6.2 Snap Icon

1. 상단 **자석 아이콘 (Snap)** 활성화
2. Snap Target → **Increment** 또는 **Grid**
3. `G` → `Z` 또는 마우스 휠 클릭으로 이동
4. 바닥면에 붙이기

### 2.6.3 Origin to Z=0

1. 오브젝트 선택
2. `Tab` → Edit Mode
3. 가장 아래쪽 Vertex/Face 선택
4. `Shift` + `S` → **Cursor to Selected**
5. `Tab` → Object Mode
6. Object → Set Origin → Origin to 3D Cursor
7. `N` → Location에서 **Z = 0** 입력

## 2.7 복제

### 2.7.1 Shift + D

- 완전히 새로운 오브젝트 생성
- 메쉬 데이터까지 **독립적으로 복제**됨

### 2.7.2 Alt + D

- 오브젝트는 여러 개지만
- **메쉬 데이터는 공유됨**
- 하나의 Edit 수정 → 모든 오브젝트에 동시에 반영
- 위치, 회전, 스케일은 각각 다르게 가능

## 2.8 Origin

<mark>Origin은 오브젝트의 **기준점**이다.</mark>

- Origin이 가운데 → 제자리에서 회전
- Origin이 바깥 → 원을 그리며 회전

Origin 확인 방법  

- 오브젝트 중심의 작은 점(주황색)
- 선택 시 표시됨

### 2.8.1 Origin 이동 1

Object → Set Origin

- Origin to Geometry → 형태 중심으로 이동
- Origin to 3D Cursor → 커서 위치로 이동

### 2.8.2 Origin 이동 2

1. Edit Mode에서 기준 위치 선택
2. `Shift` + `S` → Cursor to Selected
3. Object Mode → Origin to 3D Cursor

# 3. 실습

## 실습 1. Modifier 복습 및 적용

1. STL로 불러온 오브젝트 선택    
2. `Shift` + `D`로 오브젝트를 2개 복제    
3. 각각 이름 변경    
    - model_solid        
    - model_array        
    - model_deform        
4. 첫 번째 오브젝트에 Solidify Modifier 적용    
5. 두 번째 오브젝트에 Array Modifier 적용    
6. 세 번째 오브젝트에 Simple Deform Modifier 적용    
7. 각 Modifier 값을 조절하며 변화 확인    

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Modifier를 적용했는데 변화가 없다

원인

- 값이 너무 작음    
- 오브젝트 구조가 단순하지 않음    

해결

- Thickness, Count, Factor 값을 크게 조절    
- 단순한 모델로 다시 시도    

### 오류 2. Array가 겹쳐 보인다

원인

- Offset 값이 너무 작음    

해결

- Relative Offset 값을 증가시킴    

### 오류 3. Deform 방향이 이상하다

원인

- 축 설정이 맞지 않음    

해결

- Deform Axis를 변경하여 확인    

{{< /details >}}

## 실습 2. 분할^Inset^

1. 오브젝트 선택    
2. `Tab` → Edit Mode    
3. `3` → Face 선택 모드    
4. 상단 면 선택    
5. `I` → Inset 실행    
6. 내부에 새로운 면 생성    

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Inset이 제대로 되지 않는다

원인

- 면이 아닌 Vertex 또는 Edge 선택 상태    

해결

- Face 선택 모드 (`3`)로 변경    

### 오류 2. Inset이 너무 작거나 크다

원인

- 마우스 이동량 과다    

해결

- 천천히 드래그하거나 수치 입력    

{{< /details >}}

## 실습 3. 확장^Extrude^

1. Inset으로 만든 내부 Face 선택    
2. `E` → Extrude    
3. 위 또는 아래 방향으로 이동    

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Extrude가 이동만 된다

원인

- 기존 면을 단순 이동    

해결

- `E`를 눌러 새 면 생성 후 이동    

### 오류 2. 방향이 이상하다

원인

- 축을 제한하지 않음    

해결

- `E` → `Z` 또는 `E` → `X`/`Y`로 축 제한    

{{< /details >}}

## 실습 4. 모서리^Bevel^

1. `2` → Edge 선택 모드     
2. 모서리 선택    
3. `Ctrl` + `B` → Bevel    
4. 마우스로 두께 조절    
5. 휠로 세그먼트 증가    

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Bevel이 적용되지 않는다

원인

- Edge가 선택되지 않음    

해결

- Edge 선택 모드로 전환 후 다시 시도    

### 오류 2. 모양이 깨진다

원인

- 구조가 너무 단순하거나 복잡함    

해결

- 최소한의 Loop Cut 추가 후 적용    

{{< /details >}}

## 실습 5. 제거^Boolean^

1. Cube 생성    
2. Cylinder 생성    
3. Cube 선택    
4. Modifier → Boolean 추가    
5. Operation: Difference    
6. 대상 오브젝트로 Cylinder 선택    

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 구멍이 생기지 않는다

원인

- 두 오브젝트가 겹치지 않음    

해결

- Cylinder가 Cube를 관통하도록 위치 조정    

### 오류 2. 형태가 깨진다

원인

- 메시 구조 부족    

해결

- 단순한 구조로 다시 시도    
- 필요 시 Loop Cut 추가    

{{< /details >}}

## 실습 6. 결과 비교 및 확인

1. 각 오브젝트를 나란히 배치 (`G` → `X`)    
2. Modifier ON/OFF 반복    
3. 결과 변화 관찰    

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 차이가 잘 보이지 않는다

원인

- 오브젝트가 겹쳐 있음    

해결

- 위치를 분리하여 배치    

### 오류 2. Modifier 효과가 사라진다

원인

- Modifier 비활성화    

해결

- Modifier 체크 상태 확인    

{{< /details >}}

## 실습 7. STL 파일 내보내기

1. 내보낼 오브젝트 선택    
2. 상단 메뉴  
	File → Export → STL (.stl)    
3. 파일명 입력    
4. 필요 시 Selection Only 체크    
5. 저장    

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 다른 오브젝트까지 같이 저장된다

원인

- 여러 오브젝트 선택 상태    

해결

- 원하는 오브젝트만 선택    
- Selection Only 사용    

### 오류 2. 파일을 찾기 어렵다

원인

- 저장 위치 확인 안 함    

해결

- 저장 경로 확인 후 지정

# 4. 정리

1. Modifier는 형상을 직접 만드는 도구가 아니라 구조를 변형하는 도구이다
2. Inset은 구조를 나누고, Extrude는 구조를 확장한다
3. Bevel은 모서리를 완화하고, Boolean은 구조를 제거하거나 결합한다
4. Edit와 Modifier는 역할이 다르며, 구조 → Modifier → Edit 순서로 작업한다
