# 2. Boolean Workflow

## 2.1 Boolean의 개요

<h3>Boolean이란?</h3>

Boolean은 <mark>오브젝트와 오브젝트 사이의  
공간 관계를 계산하는 기능</mark>이다.

기능형 오브젝트는 대부분   
홈, 슬롯, 삽입부, 구멍, 결합 구조 등을 포함하며,  
Boolean은 이 구조를 <mark>오브젝트 간의  
공간 계산으로 만드는 방식</mark>이다.

Boolean은 구멍 뚫기나 자르기 정도로 보일 수 있지만,  
실제로는 **절삭**, **결합**, **공통 영역 계산** 등으로  
기능형 구조를 설계하는 방식에 가깝다.  

<h3>Boolean의 세 가지 기본 방식</h3>

1. **Difference**  
   * 다른 오브젝트의 부피를 제거
   * 슬롯, 홈, 삽입 구조 제작

2. **Union**
   * 여러 오브젝트를 하나의 부피로 결합
   * 손잡이, 지지대, 구조 추가

3. **Intersect**
   * 겹친 영역만 남김
   * 특수 구조, 교차 구조 제작

## 2.2 Difference

Difference는 <mark>선택된 오브젝트에서  
다른 오브젝트의 부피를 제거하는 기능</mark>이다.  
cf. 카드 슬롯, 케이블 홈, 스탬프 음각 등  

1. 기본 오브젝트 생성
2. 절삭용 오브젝트 생성
3. 두 오브젝트를 겹치게 배치
4. Modifier → Boolean
5. Operation → Difference 선택
6. 대상 오브젝트 지정

<h3>주의점</h3>

1. 충분히 겹쳐야 한다
   * 겹침 부족 시 변화 없음

2. 홈 깊이가 너무 얕으면 안 된다
   * 출력 시 막힐 수 있음

3. Clearance를 고려해야 한다
   * 최소 0.2~0.3mm 권장

## 2.3 Union

Union은 <mark>여러 오브젝트를  
하나의 부피로 결합하는 기능</mark>이다.  
cf.  손잡이, 지지대, 장식 구조 등  

1. 기본 오브젝트 생성
2. 결합용 오브젝트 생성
3. 충분히 겹치게 배치
4. Modifier → Boolean
5. Operation → Union 선택
6. 대상 오브젝트 지정

<h3>주의점</h3>

1. 접합 면적이 작으면 쉽게 부러질 수 있음
2. 내부 구조가 겹치지 않도록 확인한다
3. Merge by Distance로 정리하는 것이 좋다

## 2.4 Intersect

Intersect는 <mark>겹치는 영역만 남기는 기능</mark>이다.

1. 두 오브젝트 생성
2. 일부 영역이 겹치게 배치
3. Modifier → Boolean
4. Operation → Intersect 선택
5. 결과 확인

## 2.5 Boolean 사용 전 점검

1. `Ctrl` + `A` → Scale 적용
2. Face Orientation 확인
3. Merge by Distance 실행
4. 단순 구조 유지
5. 충분한 겹침 확보

- Scale 미적용
- Non-manifold 구조
- 면 방향 오류
- 겹침 부족
- 메시 과다

# 3. 화면과 출력의 차이

## 3.1 얇은 구조 문제

**화면에서는 보이지만 출력에서는 사라지는 구조**  
Blender 화면에서는 매우 얇은 구조도 형태처럼 보인다.  
<mark>너무 얇은 구조는 슬라이서 단계에서 사라질 수 있다.</mark>

<h3>대표 원인</h3>

1. 노즐 두께보다 얇음
2. 메시 자체가 지나치게 얇음
3. STL 해상도 부족
4. 출력 방향 문제

<h3>예방 방법</h3>

1. 최소 두께(1~2mm 이상) 확보
2. Solidify 사용
3. 3D WOX에서 슬라이싱 확인
4. 너무 작은 디테일 제거

## 3.2 Clearance 부족

**화면에서는 들어맞지만 출력하면 안 맞는 구조**  
Blender에서는 두 구조가 정확히 맞아 보이지만,  
실제 출력에서는 맞지 않거나 움직이지 않는다.  
<mark>“딱 맞는 구조”는 실제로는 맞지 않을 가능성이 높다.</mark>

<h3>대표 원인</h3>

* 재료 팽창
* 냉각 수축
* 적층 오차

<h3>권장 간격</h3>

| 구조      | 권장 간격     |
| - | - |
| 끼워맞춤    | 0.2~0.3mm |
| 움직이는 구조 | 0.4mm 이상  |

<h3>예방 방법</h3>

1. Clearance 확보
2. Vertex Snap으로 정확 정렬
3. N 패널에서 실제 치수 확인
4. 작은 테스트 출력 먼저 진행

## 3.3 Boolean 홈 막힘

**화면의 홈이 출력에서 막히는 문제**

<h3>대표 원인</h3>

1. 홈 깊이 부족
2. 두께 부족
3. Clearance 부족
4. 노즐 두께 제한

<h3>예방 방법</h3>

1. 충분한 깊이 확보
2. 최소 두께 유지
3. Difference 후 구조 확인
4. WOX 슬라이싱 결과 확인

## 3.5 Shade Smooth 착시

**부드럽게 보이지만 실제로는 각진 구조**

1. Face Orientation 확인

# 4. Sculpting

## 4.1 Sculpting의 개요

<h3>Sculpting이란?</h3>

Sculpting은 <mark>점^Vertex^을  
직접 밀고 당기며 형태를 조형하는 기능</mark>이다.

<h3>Sculpting의 핵심 특징</h3>

1. 직관적이다
   * 실제 점토 조각과 유사

2. 형태를 빠르게 만든다
   * 덩어리 조형에 강함

3. 메시 밀도가 중요하다
   * Vertex 수가 많아야 함

4. 출력 전 정리가 필요하다
   * 메시 과다
   * Non-manifold
   * Surface 오류

## 4.2 Sculpt Mode

<h3>Sculpt Mode 진입</h3>

1. Object 선택
2. 좌측 상단 Mode 메뉴
3. Sculpt Mode 선택

<h3>Sculpting 전 준비</h3>

Sculpting은 Vertex를 직접 움직이는 작업이다.  
<mark>메시 밀도가 충분하지 않으면 아무 변화도 생기지 않는다.</mark>  
Sculpting 전에는 다음 기능으로 메시 밀도를 높인다.

* Subdivision
* Remesh
* Voxel

<h3>준비 방식</h3>

1. Cube 또는 Sphere 생성
2. Subdivision Surface 추가
3. Levels 증가
4. Sculpt Mode 진입

또는

1. Sculpt Mode
2. Remesh
3. Voxel Size 조절
4. Remesh 실행

**형태 전체 밀기**

- `F` → 브러시 반경(크기) 조정  
- `Shift` + `F` → 브러시 강도 조정
- `Shift` + 드래그  → Smooth

## 4.5 Sculpt와 메시 밀도

메시 밀도는 <mark>모델을 구성하는   
Vertex 수와 면 수</mark>를 의미한다.

* Vertex가 적으면 세부 표현 불가능
* Vertex가 많으면 세밀한 조형 가능

메시 밀도가 너무 높으면  
오류 발생 위험도 함께 높아진다.

* STL 용량 증가
* 출력 시간 증가
* Boolean 오류 증가

# 5. 팁

## 5.1 Knife Tool

<h3>기본 흐름</h3>

1. `Tab` → Edit Mode
2. `K` → Knife Tool
3. 점 클릭
4. 선 연결
5. `Enter` → 확정

<h3>방향 맞추기</h3>

1. 축 고정
- Knife 사용 중 `X`/`Y`/`Z` 입력

2. Angle Snap
- Knife 사용 중 `C` 입력

3. Vertex 기준 절단
- Vertex를 직접 클릭해 기준점끼리 연결

<h3>길이와 크기 맞추기</h3>

1. Grid, Increment Snap 병행
- Knife 이전에 Grid 기준 구조 생성 후 절단

2. Loop Cut 병행
- `Ctrl` + `R` 로 먼저 분할 후 Knife로 세부 수정

3. Bisect
- `F3` → Bisect

4. Vertex/Edge Slide
- `GG` → Vertex/Edge를 Edge/Face를 따라 이동

5. Cut Through
- `Z` → 뒤쪽 면까지 관통 절단

6. Midpoint Snap
- `Shift` → 중간점 스냅 보조

## 5.2 Screw Modifier

1. `Shift` + `A`
2. Mesh → Plane 생성
3. `Tab` → Edit Mode
4. Vertex 3개 삭제
5. Vertex 하나만 남김
6. `E` → 짧은 선 생성
7. Object Mode 복귀
8. Modifier → Screw 추가

# 6. 정리

1. Boolean은 단순 구멍 뚫기가 아니라 기능 구조를 설계하는 방식이다
2. Blender 화면에서 정상처럼 보여도 실제 출력에서는 얇은 구조, Clearance 부족, Overhang 문제 등이 발생할 수 있다
3. Sculpting은 디지털 조각 방식이며, 형태 조형에는 강하지만 메시 밀도와 출력 안정성을 함께 고려해야 한다
