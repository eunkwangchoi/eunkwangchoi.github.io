# 2. 3D란 무엇인가

## 2.1 3D

<mark>3D는 **세 개의 축으로 이루어진 공간**이다.</mark>

- X축 : 좌우  
- Y축 : 앞뒤  
- Z축 : 위아래  

## 2.2 오브젝트

<mark>3D 오브젝트^Object^는 **공간에 존재하는 하나의 물체**이다.</mark>  
<mark>스크린 내의 오브젝트는 모두 **좌표 + 구조**로 구성/계산/저장된다.</mark>

- 주사위(정육면체)^Cube^ 
- 통(원기둥)^Cylinder^
- 고깔(원뿔)^Cone^
- 공(구)^Sphere^

## 2.3 메시

<mark>메시^Mesh^는 스크린 내 3D **오브젝트의 구조**를 의미한다.</mark>

- 점^Vertex^
- 선^Edge^
- 면^Face^

## 2.4 모델링

<mark>모델링^Modeling^은 **메시를 다듬는 작업**이다.</mark>  
<mark>즉 **점, 선, 면을 이용해 형태를 만드는 작업**이다.</mark>

<br>

# 3. 블렌더의 인터페이스

## 3.1 뷰

- 뷰^View^, 뷰포트^Viewport^, 뷰 창, 메인 화면 등으로 부름
- 모델을 확인하고 직접 작업을 수행하는 영역

## 3.2 아웃라이너

- 아웃라이너^Outliner^
- 장면^Scene^에 존재하는 모든 오브젝트 목록
- 오브젝트를 관리하고 **선택**하는 창

## 3.3 속성

- 오브젝트의 속성^Properties^을 조정하는 영역
- 크기, 위치, 회전각 등

## 3.4 툴바

- 툴바^Toolbar^에는 기본적인 (오브젝트) 조작 도구가 있음 
- 재설정^User Customizing^할 수 있음

<br>

# 4. 블렌더의 기본 조작

## 4.1 뷰 조작

<mark>화면의 조작! 오브젝트를 움직이는 것이 아니다.</mark>

- 회전 : 중클릭 드래그  
- 이동 : `Shift` + 중클릭  
- 확대 : 마우스 휠  

## 4.2 오브젝트 조작

<mark>오브젝트를 **선택**한 후 조작한다.</mark>

- 이동 : `G`  
- 회전 : `R`  
- 크기 : `S`  

<br>

# 5. 블렌더의 기본 개념

## 5.1 오브젝트

<mark>오브젝트는 블렌더의 기본 단위이다.</mark>  
<mark>블렌더의 모든 작업은 오브젝트로 명명된다.</mark>

- Cube = <mark>**Object**</mark> = Camera = Light

## 5.2. 모디파이어

<mark>모디파이어^Modifier^는 형상을 직접 바꾸지 않고 속성을 추가하는 기능이다.</mark>  
<mark>블렌더는 편집^Edit^보다 모디파잉을 중심으로 삼는 애플리케이션이다.</mark>

- 수정자, 수식, 인덱스^index^ 등으로 번역(?)됨
- 블렌더 모델링에서 핵심이 되는 개념이자 기능
- 예시 : 형태의 한쪽만 만들고 미러^Mirror^를 적용하면 반대쪽이 함께 생성됨
- 특징 : 형태 변형 없이 수정 및 삭제 가능

{{< details summary="실습 과정 자세히 보기" >}}

### 1단계. Cube 선택

화면 중앙의 **Cube**를 클릭하여 선택한다.  
선택되면 오브젝트 가장자리가 강조되어 보인다.

- Outliner에서도 Cube가 선택되어 있어야 한다.
- 다른 오브젝트^Camera, Light^가 선택되지 않도록 한다.

### 2단계. Object Mode 확인

Mirror Modifier는 오브젝트 단위 기능이다.  
현재 모드가 **Object Mode**인지 확인한다.

- Viewport 왼쪽 위의 모드 표시를 본다.
- Object Mode로 되어 있어야 한다.
- 만약 Edit Mode라면 `Tab` 키를 눌러 Object Mode로 전환한다.

### 3단계. Edit Mode로 들어가기

이제 Cube의 절반을 없애기 위해 **Edit Mode**로 들어간다.

- `Tab` 키를 누른다.
- 또는 왼쪽 위 모드 메뉴에서 Edit Mode를 선택한다.

### 4단계. 면 선택 모드로 전환

Cube의 절반을 삭제하려면 면^Face^을 선택하는 것이 가장 쉽다.

- 키보드 `3`을 눌러 Face Select 모드로 전환한다.
- 또는 화면 상단의 Face 아이콘을 클릭한다.

### 5단계. Cube의 한쪽 면 선택

- Cube의 왼쪽 또는 오른쪽 바깥 면 하나를 선택한다.
- 선택한 면이 주황색으로 표시되는지 확인한다.

### 6단계. 절반 삭제를 위한 분할

기본 Cube는 한 개의 덩어리이다.  
바깥 면 하나만 지우는 것으로는 “절반 삭제”가 되지 않는다.  
따라서 먼저 Cube를 가운데에서 나누어야^Loop Cut^ 한다.

1. `Ctrl` + `R`을 누른다.  
2. Cube 중앙에 절단선이 생기면 클릭하여 확정한다.  
3. 마우스를 움직이지 말고 다시 한 번 클릭하면 중앙에 정확히 배치된다.

이제 Cube는 좌우 두 부분으로 나뉜 상태가 된다.

### 7단계. 절반 면 선택 후 삭제

이제 Cube의 오른쪽 절반을 삭제한다.

1. 다시 Face 선택 모드 상태를 확인한다.  
2. 오른쪽 절반의 바깥쪽 면과 필요한 면들을 선택한다.  
3. `X` 키를 누른다.
4. 메뉴에서 Faces를 선택한다.

이제 우리는 **절반짜리 원본**을 준비했다.

### 8단계. Object Mode로 돌아가기

Modifier는 Object 단위로 적용된다.  
그러므로 다시 Object Mode로 돌아간다.

- `Tab` 키를 누른다.

### 9단계. Modifier 패널 열기

오른쪽 **Properties** 영역에서  
렌치 모양 아이콘^Modifier 탭^을 클릭한다.

이 패널은 오브젝트에 기능을 추가하는 곳이다.

### 10단계. Mirror Modifier 추가

다음 순서로 진행한다.

1. Add Modifier 클릭  
2. Mirror 선택

반쪽만 남아 있던 Cube가 다시 좌우 대칭 구조로 보인다.  
실제로는 우리가 절반만 만들었지만,  
Mirror Modifier가 나머지 절반을 **가상으로 생성**하고 있는 것이다.  
  
겉보기에 오브젝트는 완전한 형태처럼 보이지만,  
실제로 편집 가능한 원본은 절반뿐이다.  
  
Edit Mode로 들어가서 남아 있는 한쪽을 움직이면 반대쪽도 함께 변한다.  

### 추가 1단계. Modifier 켜기/끄기

Modifier 패널에서  
Mirror Modifier의 표시 아이콘을 눌러 효과를 잠시 꺼 본다.

- 끄면 : 절반만 남는다
- 켜면 : 다시 대칭 구조가 나타난다

### 추가 2단계. Edit Mode에서 한쪽만 수정하기

1. Mirror Modifier가 켜진 상태에서 `Tab`으로 Edit Mode 진입
2. 남아 있는 한쪽의 Vertex나 Face를 선택
3. `G` 키로 이동

수정한 한쪽만 바뀌는 것이 아니라 반대편도 동시에 대칭으로 변한다.

### 오류 1. Mirror를 추가했는데 아무 변화가 없다

원인

- 원래 Cube가 전체 그대로 남아 있음
- 절반을 삭제하지 않았음

해결

- Edit Mode에서 절반을 먼저 삭제한다.

### 오류 2. 대칭 기준이 이상하다

원인

- 오브젝트 중심점^Origin^이 적절하지 않음
- 중앙 축 기준으로 잘리지 않았음

해결

- 처음에는 기본 Cube 상태에서 중앙 절단 후 진행한다.
- 복잡한 오브젝트는 나중에 Origin 개념을 따로 다룬다.

### 오류 3. 가운데가 붙지 않고 틈이 생긴다

원인

- 중앙선이 정확히 축 위에 놓이지 않음

해결

- 처음 실습에서는 정중앙 Loop Cut을 사용한다.
- 필요하면 Mirror Modifier의 Clipping 옵션을 켠다.


### 오류 4. X/Y/Z 축을 선택했는데 Mirror가 확장되지 않는다

원인

- Mirror Modifier의 축^X/Y/Z^이 올바르게 설정되지 않음
- 오브젝트가 중심^Origin^ 기준선에 맞지 않음
- 모델이 실제로는 다른 축 방향으로 분할되어 있음

해결

- Modifier 축 설정 확인 : Mirror Modifier에서 X/Y/Z 체크 상태 확인
- 오브젝트 중심^Origin^ 확인 : **중앙이 기준**, 필요 시 Object → Set Origin → Origin to Geometry 적용
- 축 방향 재확인 : 다른 축^Y, Z^을 선택해 확인

# 참고. 3D WOX와 블렌더의 차이

## 2.1 기존 경험

3D WOX에서의 작업 방식

- 직접 형태를 만든다
- 기능 중심 (Extrude, Fillet 등)
- 결과가 바로 확정된다
- 수정이 어렵다

## 2.2 Blender의 경험

Blender에서는

- 구조를 만든다
- 과정을 유지한다
- 언제든 수정할 수 있다

## 2.3 핵심 차이

| 구분 | 3D WOX | Blender |
|---|---|---|
| 작업 방식 | 직접 수정 | 구조 관리 |
| 중심 | 결과 | 과정 |
| 수정 | 어려움 | 쉬움 |
| 반복 | 수작업 | 자동 |
