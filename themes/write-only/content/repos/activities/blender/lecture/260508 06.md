# 1. 강의 개요

<h3>강의명</h3>

출력 설계  
— 실패하지 않는 프린팅 구조

<h3>강의 목표</h3>

- 출력 가능한 구조를 계획할 수 있다.
- 바닥면과 같은 3D 프린팅의 기본 조건을 이해할 수 있다.
- 겹친 요소 등 메시 오류를 점검할 수 있다.
- 오브젝트를 정확하게 정렬할 수 있다.
- 오브젝트의 출력 조건을 점검할 수 있다.

<h3>실습의 흐름</h3>

1. 얇은 구조 비교 — Solidify, Thickness, Apply Scale
2. 오버행 구조 비교 — Extrude, Rotation, Support 확인
3. 메시 오류 정리 — Merge by Distance, Face Orientation, Recalculate Outside
4. 오브젝트 정합 — Vertex Snap, Face Snap, Grid Snap
5. 끼워맞춤 구조 — Clearance, Scale, Numeric Input
6. 출력 전 점검 — Selection Only, STL Export, 3D WOX 확인

<br>

# 2. 출력 가능한 구조

## 2.1 두께^Thickness^

<mark>3D 프린팅에서 **두께**는 가장 먼저 확인해야 할 조건이다.</mark>  

* 최소 두께: 약 0.8 ~ 1mm 이상  
* 안정적인 구조: 약 1.5 ~ 2mm 이상  
* 손으로 자주 만지는 기능형 오브젝트: 2mm 이상 권장  

얇은 구조는 다음 문제로 이어진다.  

* 출력 중 끊어짐  
* 출력 후에도 쉽게 파손됨  
* 슬라이서에서 일부 구조가 무시됨  

<mark>얇은 판이나 면에 두께를 부여할 때 **Solidify**를 사용할 수 있다.</mark>  
두께를 만든 뒤에도 Dimensions, Scale, 출력 방향을 다시 확인해야 한다.  

<h3>확인 작업</h3>  

1. 얇은 판 형태 오브젝트 선택  
2. Modifier → Solidify 적용  
3. Thickness 값을 바꾸어 가며 비교  
4. Wireframe 또는 측면 View에서 두께 확인  
5. 출력용 모델은 지나치게 얇지 않도록 수정  

## 2.2 오버행^Overhang^

<mark>**오버행**은 아래에 받치는 구조 없이 공중으로 돌출된 부분을 말한다.</mark> 

3D 프린터는 아래에서 위로 재료를 쌓아 올린다.  
공중에 갑자기 생기는 구조는 안정적으로 출력하기 어렵다.   
<mark>일반적으로 많이 쓰는 기준은 **45도 규칙**이다.</mark>    

수직 기준으로 완만하게 기울어진 구조는 비교적 안정적이다.  
수평에 가까운 돌출부는 **서포트**가 필요할 수 있다.  
<mark>**서포트**는 공중 구조를 받쳐 주는 임시 구조물이다.</mark>  

다만 서포트는 출력 후 제거해야 한다.  
더불어 출력물의 표면을 거칠게 만든다.  
처음부터 서포트가 적게 필요한 형태로 설계하는 것이 좋다.  

<h3>확인 작업</h3>   

1. Cube 또는 판 구조를 하나 만든다  
2. 하나는 30~45도 정도 기울인다  
3. 다른 하나는 수평에 가깝게 돌출시킨다  
4. 두 구조를 비교한다  
5. 어느 구조에 서포트가 필요할지 판단한다  

## 2.3 바닥면^Grounding^

<h3>좋은 바닥면의 조건</h3>  

* 평평한 면이 있다  
* 접지 면적이 충분하다  
* 모델이 바닥에서 뜨지 않는다  
* 작은 조각이 따로 떨어져 있지 않다  
* 불필요한 돌출물이 아래쪽에 없다  

<h3>확인 작업</h3>   

1. 모델을 측면에서 본다  
2. 바닥 전체가 Z=0에 닿는지 확인한다  
3. 바닥 아래로 튀어나온 작은 조각이 있는지 확인한다  
4. 필요하면 작은 섬 구조를 삭제한다  
5. 3D WOX에서 불러온 뒤 바닥 배치 상태를 다시 확인한다

# 3. 메시 오류와 구조 정리

## 3.1 Non-Manifold

<mark>**Non-Manifold**는 실제 물체로 해석하기 어려운 메시 구조를 말한다.</mark>  
3D 프린터는 모델의 안과 밖을 구분해야 한다.  
Non-manifold 구조에서는 이 구분이 불명확해진다.  

<h3>대표적인 열린 구조</h3>

* 면이 빠져 구멍이 난 구조  
* 한쪽만 있는 얇은 면  
* 닫히지 않은 박스  
* 내부와 외부가 연결된 구조  

**내부 면**도 문제를 만든다.  
닫힌 물체처럼 보이지만 안쪽에 불필요한 면이 남아 있으면  
슬라이서가 구조를 잘못 해석할 수 있다.  

<h3>대표적인 출력 오류</h3>  

* 일부가 출력되지 않음  
* 내부 채움이 이상하게 생성됨  
* 표면에 구멍이 생김  
* 슬라이서에서 경고가 표시됨  

<h3>확인 작업</h3>  

1. Wireframe으로 내부 구조 확인  
2. X-Ray를 켜고 내부 면이 있는지 확인  
3. 열린 구멍이 있는지 확인  
4. 필요하면 면을 채우거나 불필요한 내부 면을 삭제한다  

## 3.2 겹친 점과 면

겹친 점과 면은 눈으로 보기 어렵지만 출력 오류의 원인이 된다.   
<mark>가까이 있는 Vertex를 하나로 병합할 때는 **Merge by Distance**를 사용한다.</mark>  

1. `Tab` → Edit Mode  
2. `A` → 전체 선택  
3. `M` → By Distance  
4. 병합된 Vertex 수 확인  

Extrude를 실행한 뒤 같은 위치에 면이 겹친 경우,  
정상처럼 보이지만 중복 구조가 남을 수 있다.  

오브젝트끼리 붙어 있는 듯 보이지만 서로 관통하고 있거나,  
반대로 아주 작은 틈이 있을 수 있다.  

<h3>확인 작업</h3>   

1. Wireframe 또는 X-Ray로 내부 확인  
2. 겹친 점이 의심되면 Merge by Distance 실행  
3. 오브젝트가 겹치는 부분은 의도된 결합인지 확인  
4. 불필요한 내부 면은 삭제한다  

## 3.3 Face Orientation 재점검  

3D 모델의 면은 안쪽과 바깥쪽을 가진다.  
<mark>면의 방향을 확인할 때는 **Face Orientation**을 사용한다.</mark>  

* 빨강: 안쪽 방향  

<mark>**빨간 면**이 겉에 보인다면 면이 뒤집힌 상태일 수 있다.</mark>  
뒤집힌 면은 다음 문제를 만든다.

* 슬라이서가 내부와 외부를 잘못 판단  
* 일부 면이 출력되지 않음  
* Boolean 결과가 이상해짐  
* Non-manifold 오류와 결합될 수 있음  

<h3>바깥 방향 재계산</h3> 

1. `Tab` → Edit Mode  
2. `A` → 전체 선택  
3. `Alt` + `N`  
4. Recalculate Outside  

<h3>확인 작업</h3>  

1. Overlay → Face Orientation 체크  
2. 겉면에 빨강이 보이는지 확인  
3. 빨간 면이 있으면 Recalculate Outside 실행  
4. 그래도 남는 면은 개별적으로 Flip 확인

# 4. 정합^Fitting^

## 4.1 Increment/Grid Snap

1. Cube 생성
2. 상단 자석 아이콘 활성화
3. Snap Type → **Increment** 또는 **Grid** 선택
4. `G`로 이동
5. 격자 기준으로 이동하는지 확인
6. `N` 패널에서 Location 값 비교

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 자유롭게 움직인다

원인

* Snap 비활성화
* Snap Type 미설정

해결

* 자석 아이콘 활성화
* Increment 또는 Grid 선택

### 오류 2. 격자에 맞지 않는 것처럼 보인다

원인

* 시점^View^ 때문에 착시 발생

해결

* Top View 또는 Front View에서 확인
* `N` 패널로 수치 확인

{{< /details >}}

## 4.2 Vertex Snap

1. Cube 2개 생성
2. Snap Type → **Vertex**
3. `G`로 이동
4. 한 Cube의 Vertex를 다른 Cube Vertex에 맞춤
5. Wireframe 또는 X-Ray로 틈 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Snap이 되지 않는다

원인

* 자석 아이콘 비활성화
* Snap Type 오류

해결

* Snap 활성화
* Vertex Snap 선택

### 오류 2. 이상한 위치로 붙는다

원인

* 잘못된 Vertex를 기준으로 잡음

해결

* 확대 후 목표 Vertex 위에서 이동 종료

{{< /details >}}

## 4.3 Edge Snap

1. Plane 생성
2. `Shift` + `D`로 복제
3. Snap Type → **Edge**
4. `G`로 이동
5. Edge끼리 맞춤
6. 겹침 또는 틈 여부 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 면 중심으로 붙는다

원인

* Face Snap 상태

해결

* Edge Snap으로 변경

### 오류 2. 완전히 일치하지 않는다

원인

* Edge 방향 불일치

해결

* 회전 후 다시 Snap

{{< /details >}}

## 4.4 Face Snap

1. Plane 생성
2. Cube 생성
3. Snap Type → **Face**
4. `G`로 Cube 이동
5. Plane 표면 위에 배치
6. 측면 View에서 접지 상태 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Cube가 바닥 안으로 들어간다

원인

* Origin 기준 이동

해결

* Origin 위치 확인
* 바닥 기준 Origin 재설정

### 오류 2. 정확히 붙지 않는다

원인

* Face Snap 미활성화
* 잘못된 Face 선택

해결

* Face Snap 재확인
* 측면 View에서 재시도

{{< /details >}}

## 4.5. Align Rotation to Target

1. Plane 생성
2. `R` → `X`로 Plane 기울이기
3. Cube 생성
4. Snap Type → Face
5. **Align Rotation to Target** 체크
6. Cube를 Plane 위에 이동
7. 회전 방향 변화 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 방향이 따라가지 않는다

원인

* Align Rotation 비활성화

해결

* 옵션 체크 확인

### 오류 2. 이상한 방향으로 회전한다

원인

* Origin 방향 문제
* Rotation 상태 꼬임

해결

* Apply Rotation 확인
* Origin 위치 점검

{{< /details >}}

## 4.6. Snap + Origin

1. Cube 생성
2. Face Snap으로 바닥에 배치
3. 결과 확인
4. Edit Mode에서 바닥 Vertex 선택
5. `Shift` + `S` → Cursor to Selected
6. Object → Set Origin → Origin to 3D Cursor
7. 다시 Face Snap 수행
8. 결과 비교

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. Origin이 움직이지 않는다

원인

* Edit Mode 상태

해결

* Object Mode에서 Set Origin 실행

### 오류 2. Snap 결과가 여전히 이상하다

원인

* Origin 위치가 원하는 기준이 아님

해결

* 바닥 Vertex 기준으로 다시 Origin 설정

{{< /details >}}

## 4.7. Snap + Clearance

1. Cube 생성
2. `Shift` + `D`로 복제
3. Snap과 `N` 패널을 사용하여 간격 설정
   * 0mm
   * 0.2mm
   * 0.5mm
4. Wireframe으로 간격 비교
5. 어떤 구조가 실제 출력에 적합할지 토론

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 2. 오브젝트가 겹친다

원인

* Clearance 미적용

해결

* 최소 0.2mm 이상 간격 확보

### 오류 3. 틈이 너무 커 보인다

원인

* 실제 프린팅 오차를 고려하지 않음

해결

* 출력용 구조는 약간의 여유가 필요함을 이해

# 5. 출력 전 최종 점검  

## 5.1 Apply Scale  

<mark>Blender에서 `S`로 크기를 조정해도 Scale 값은 1이 아닐 수 있다.</mark>  
Apply Scale은 현재 크기를 실제 기준값으로 확정하는 작업이다.  

1. Object 선택  
2. `Ctrl` + `A`  
3. Scale 선택  
4. N 패널에서 Scale 값이 1, 1, 1인지 확인  

Rotation이나 Location Apply를 무분별하게 사용하지 않는 편이좋다.  
출력 전 기본 점검에서는 우선 Scale 적용을 중심으로 한다.  

## 5.2 STL Export

<h3>출력용 파일 정리</h3>  

* 필요한 오브젝트만 선택  
* Selection Only 사용  
* 파일명에 버전 표시  
* 저장 위치 확인  
* 불필요한 Camera, Light, 테스트 오브젝트 제외  

<h3>작업 흐름</h3>  

1. 출력할 오브젝트만 선택  
2. File → Export → STL  
3. Selection Only 체크  
4. 파일명 입력  
5. 저장 위치 확인 후 Export  

<h3>파일명 예시</h3>  

* cable_clip_v1.stl  
* card_holder_test_02.stl  
* bookmark_final_01.stl  

## 5.3 3D WOX 확인  

3D WOX에서 확인할 항목  

* STL 불러오기  
* 바닥 정렬  
* 출력 방향  
* 모델 크기  
* 예상 출력 상태 확인  

예상 출력 상태 확인에서는 다음을 본다.  

* 첫 레이어가 안정적인가  
* 서포트가 필요한가  
* 출력 시간이 과도하지 않은가  
* 얇은 구조가 누락되지 않았는가  
* 모델 일부가 비어 보이지 않는가

# 6. 실습

## 실습 1. 얇은 구조 vs 출력 가능한 구조

1. Plane 생성
2. `Tab` → Edit Mode
3. `E` → Extrude로 얇은 구조 생성
4. Object Mode 복귀
5. Solidify Modifier 추가
6. Thickness 값을 0.2 → 1 → 2로 변경하며 비교
7. 측면 View에서 두께 변화 확인

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 두께 변화가 잘 보이지 않는다

원인

* Thickness 값이 너무 작음
* 정면에서만 보고 있음

해결

* Thickness 값을 크게 조절
* 측면에서 확인

### 오류 2. 구조가 깨져 보인다

원인

* 메시 구조가 단순하지 않음
* 뒤집힌 면 존재

해결

* `Alt` + `N` → Recalculate Outside
* 단순 구조에서 다시 시도

{{< /details >}}

## 실습 2. 오버행 구조 비교

1. Cube 생성
2. `Shift` + `D`로 복제
3. 첫 번째 Cube → `R` → `X` → 약 30도 회전
4. 두 번째 Cube → `R` → `X` → 90도에 가깝게 회전
5. 두 구조를 나란히 배치
6. 어느 구조에 서포트가 필요할지 비교

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 회전 방향이 이상하다

원인

* 축 제한 미사용
* Global / Local 방향 혼동

해결

# 7. 정리

1. 3D 프린팅에서는 “보이는 형태”보다 **출력 가능한 구조**가 중요하다
2. 얇은 구조는 출력되지 않거나 쉽게 파손될 수 있으므로 충분한 두께가 필요하다
3. 오버행이 큰 구조는 서포트가 필요할 수 있으며, 가능하면 출력 방향과 구조를 먼저 조정한다
4. 바닥면은 첫 레이어의 기준이므로 평평하고 충분한 접지 면적을 가져야 한다
5. Non-manifold, 겹친 점, 뒤집힌 면은 출력 오류의 주요 원인이므로 사전에 정리한다
6. Snap, Grid, Vertex 기준 정렬은 눈대중 배치를 줄이고 오브젝트를 정확히 맞추는 데 필요하다
7. 끼워맞춤 구조에는 Clearance가 필요하며, 딱 맞는 설계는 실제 출력에서 맞지 않을 수 있다
8. 출력 전에는 Apply Scale, Face Orientation, STL Export, 3D WOX 확인을 순서대로 점검한다
