# 2. STL 파일의 개요

## 2.1 STL 파일의 개요

<h3>STL 파일이란?</h3>

STL은 **3D 모델을 저장하는 파일 형식**이다.  
<mark>3D 프린팅용 모델 데이터를 저장하는 표준 형식</mark>  
	- **Stereolithography**  
	- Standard Tessellation Language  

<h3>구조와 형식 1 - 형태의 집합</h3>

<mark>STL 파일은 3D 모델의 **형태**^geometry^만 전달한다.</mark>  
	- 모델의 외형    
	- 표면 구조    
	- 면의 방향    

다음 정보는 포함하지 않는다.  
	- 색상, 재질, 텍스처    
	- 단위 정보    
	- 애니메이션

참조: https://3dviewer.net

<h3>구조와 형식 2 - 삼각형의 집합</h3>

<mark>STL 파일은 모델을 **삼각형**^triangle^으로 나누어 저장한다.</mark>  
	- 3개의 점^Vertex^  
	- 1개의 법선 벡터^Normal^  
복잡한 모델도 “수많은 삼각형의 집합”이다.   
  
왜 삼각형인가?  

1. 항상 평면을 이룬다    
2. 계산이 단순하다    
3. 모든 형태를 분해할 수 있다
   
<h3>STL 파일의 특징</h3>

1. 단순하다
	- 색상 없음, 재질 없음, 단위 없음  
2. 호환성이 높다
	- 다양한 3D 프로그램에서 지원
	- 대부분의 3D 프린터가 지원
3. 완전 Mesh 기반이다    
	- 곡면도 실제로는 다각형으로 표현된다
	- 면이 많을수록 부드럽게 보인다

<h3>STL의 종류</h3>

1. **ASCII** STL
	- 사람이 읽을 수 있는 텍스트 형식    
	- 일반적으로 대용량

2. **Binary** STL
	- 컴퓨터가 읽는 이진 형식    
	- 용량이 작고 빠름    
	- 일반적으로 더 많이 사용됨

<h3>3D 프린팅에서 STL의 위치</h3>

모델링 → <mark>**STL**</mark> → 슬라이서 → G-code → 프린터

- Blender 등에서 모델 생성 → STL로 저장    
- 슬라이서에서 프린트용 데이터로 변환    
- 프린터에서 출력

## 2.2 STL 파일의 취급 주의점

<h3>단위 문제</h3>

<mark>STL에는 단위 정보가 없다.</mark>
- mm로 만든 모델이    
- 다른 프로그램에서는 cm로 해석될 수 있다  

<h3>메시 품질</h3>

- 면이 너무 적으면 거칠다    
- 면이 너무 많으면 무겁다

<h3>오류 구조</h3>

- 구멍이 있는 메시 (Non-manifold)    
- 뒤집힌 면 (Normal 오류)    
- 겹치는 면

## 2.3 입문자용 탐색 사이트

https://thingiverse.com

- 가장 오래되고 규모가 큰 사이트
- 처음 STL을 찾을 때 가장 무난한 출발점
- 거의 모든 종류의 모델 탐색 가능
- 초보자용 자료 다수

Tip. 다운로드 횟수 및 사진이 많은 모델 탐색

- 비교적 안정적인 모델 품질
- 깔끔한 인터페이스

Tip. **Makes** 탭이 많은 모델 위주로 탐색

https://makerworld.com

- 최근 빠르게 성장 중인 플랫폼
- 프린터 설정^Profile^ 제공 다수
- 실사용 중심 모델 다수
- 초보자용 자료 다수

Tip. 인기^Trending^ 모델 탐색  
Tip. **Print Profile**이 있는 모델 탐색

# 3. 실습

## 실습 1. STL 파일 가져오기  

1. Blender 실행  
2. 상단 메뉴에서  
    **File** → **Import** → **STL (.stl)**    
3. 샘플 STL 파일 불러오기    
4. 오브젝트가 추가되었는지 확인  
	Viewport, Outliner 

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 가져왔는데 보이지 않는다

원인

- 모델이 너무 멀리 있거나 너무 작음    
- 현재 뷰가 모델을 포착하지 못함    

해결

- Outliner에서 오브젝트 선택    
- 키패드에서 `.` 또는 Frame Selected 사용    

### 오류 2. 가져왔는데 너무 크다/작다

원인

- STL 파일의 단위 기준 차이    

해결

- 일단 지금은 크기 차이만 관찰한다    
- 오늘은 “불러오고 다루는” 데만 집중

{{< /details >}}

<br>

```
⁉️ 퀴즈 Set A‼️

(1) 3D 공간을 이루는 세 축은 무엇인가?
(2) Blender에서 3D 모델의 구조를 부르는 용어는?
(3) Blender에서 3D 모델의 구조를 이루는 세 요소는?
```

## 실습 2. 오브젝트 점검

1. 오브젝트 선택    
2. `G`로 이동해 본다    
3. `R`로 회전해 본다    
4. `S`로 크기를 바꿔 본다    
5. Outliner에서 오브젝트 이름을 바꿔 본다    
<br>

```
⁉️ 퀴즈 Set B‼️

(4) Blender에서 Cube, Camera, Light의 공통점은?
(5) 마우스 휠을 움직였을 때 바뀌는 것은 오브젝트인가, 뷰인가?
(6) 중클릭 드래그는 오브젝트를 움직이는가, 화면을 움직이는가?
```

## 실습 3. Modifier: Solidify 

1. 오브젝트 선택    
2. Properties에서 Modifier 탭(렌치🔧) 선택   
3. Add Modifier 선택    
4. Solidify 선택    
5. Thickness 값 조절     

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 두께 변화가 안 보인다

원인

- 모델이 원래 두껍거나    
- 값 변화가 너무 작다    

해결

- Thickness 값을 더 크게 조절해 본다    
- 시점을 바꾸어 측면에서 확인한다    

### 오류 2. 형태가 겹치거나 찌그러진다

원인

- STL 구조가 단순하지 않거나    
- 면 방향 또는 구조가 고르지 않다    

해결

- 지금 단계에서는 현상만 확인    
- 복잡한 샘플 대신 단순한 샘플로 실습

{{< /details >}}

<br>

```
⁉️ 퀴즈 Set C‼️

(7) Modifier는 형상을 직접 바꾸는 기능이다. (OX)
(8) Modifier를 끄면 원본의 일부가 사라진다. (OX)

```

## 실습 4. Modifier: Array 

1. 오브젝트 선택    
2. Modifier 탭에서 Add Modifier    
3. Array 선택    
4. Count 값을 늘리거나 줄여본다    
5. Relative Offset 값 조절

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 오브젝트가 겹쳐서 보인다

원인

- Offset 값이 너무 작다    

해결

- Relative Offset 값을 더 크게 조절한다    

### 오류 2. 원하는 방향으로 반복되지 않는다

원인

- X/Y/Z 중 올바른 방향 값이 선택되지 않음    

해결

- 축별 값을 하나씩 바꿔 보며 결과 확인    

{{< /details >}}

## 실습 5. Modifier: Simple Deform 

1. 오브젝트를 선택한다.    
2. Modifier 탭에서 Add Modifier    
3. Simple Deform 선택    
4. Mode 설정 (권장: Bend, Taper)
5. Factor 값을 조절해본다

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 변화가 거의 없다

원인

- Factor 값이 너무 작다    

해결

- 값을 더 크게 조절한다

### 오류 2. 기대한 방향과 다르게 변형된다

원인

- 축 방향이 맞지 않다    

해결

- Deform Axis를 바꾸어 확인한다   

{{< /details >}}

## 실습 6. Modifier 비교

1. 적용한 Modifier들을 하나씩 토글  
	- Solidify ON/OFF    
	- Array ON/OFF    
	- Simple Deform ON/OFF
2. 순서를 바꿔 본다    
3. 결과가 어떻게 달라지는지 비교    

## 실습 7. STL 파일 내보내기

1. 내보낼 오브젝트 선택    
2. 상단 메뉴에서  
	**File** → **Export** → **STL (.stl)** 
3. 파일명 입력     
4. 필요 시 Selection Only 체크    
5. STL 파일 저장  

{{< details summary="실습 과정의 오류 해결" >}}

### 오류 1. 다른 오브젝트까지 같이 저장된다

원인

- 원하는 오브젝트만 선택하지 않음    

해결

- 내보내기 전 선택 상태 확인    
- Selection Only 사용

### 오류 2. 저장 후 어떤 파일인지 헷갈린다

원인

- 파일명 규칙이 없음    

해결

- 이름에 버전과 특징을 넣는다

{{< /details >}}

⁉️ 퀴즈 Set D‼️

(9) Mesh는 ___, ___, ___(으)로 구성된다.

# 4. 정리

1. 가져온 STL도 Blender에서는 오브젝트이다    
2. Modifier는 형상을 직접 다시 만들지 않고 변형한다    
3. 같은 오브젝트를 반복하거나 속성을 변형할 수 있다    
4. 결과는 다시 STL로 내보낼 수 있다
