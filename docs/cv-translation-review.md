# CV English translation review — 2026-10-07

The supplied `Personal History EN.md` was compared with the current Korean CV data. Matching English expressions were reused. Missing or inconsistent wording was translated from Korean. Existing dates, amounts, qualification levels, IDs and archive URLs were not replaced from the older English source. Personal identifier numbers in that source were not imported.

## Coverage

English titles/names now cover every public entry, work, press record, organization and series. Entry descriptions and nonempty detail lists have English counterparts. Archive titles are stored only in `cv.title_en`; article text and original Korean titles remain intact. Book extent, thesis advisors, introduction and interests are localized. English titles of Korean publications are marked `(in Korean)`; these are translations, not claims that English editions exist.

The shared source is used by the web CV, CSL bibliography and all print variants. The validator now rejects public records with missing English titles/names, descriptions or details.

## Private reconciliation records

Item-level source discrepancies, dates, amounts and naming decisions are now
preserved in the private Obsidian CV notes. Keeping those details out of this
public repository prevents review documentation from disclosing subsequently
hidden CV entries. Translation follows the current Korean facts and reuses
matching English wording; it is not an independent factual verification.

The supplied Obsidian manuscripts remain unchanged. Official institutional
names still need owner review where the source supplies no matching English.
